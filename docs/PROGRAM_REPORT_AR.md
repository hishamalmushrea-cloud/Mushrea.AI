## 1) ما هو البرنامج في سطور

**Mushrea Code** تطبيق أندرويد أصلي (لا حاجة لطرفية أو حاسوب) يمنحك واجهة لمسية لتشغيل
**وكلاء البرمجة بالذكاء الاصطناعي** على هاتفك مباشرة، أو للاتصال بوكيل يعمل على حاسوبك:

1. **على الجهاز (On-device):** يُنزّل وينصّب بيئة لينكس مصغَّرة عبر **PRoot** (ألباين للتشغيل
   العام + دبيان Bookworm لأن Antigravity يحتاج glibc)، ثم يشغّل داخلها الوكيل المختار.
2. **بعيدًا (Remote):** يتصل بخادم **OpenCode** على PC/Mac/Linux عبر الشبكة المحلية أو Tailscale،
   مع **تبديل حيّ بين المحلي والبعيد في منتصف المحادثة** (Handoff).
3. **وكيل الجهاز (Device Agent):** يمنح الوكيل قدرة على التحكم بالهاتف نفسه (فتح تطبيقات، قراءة
   الشاشة، لمس/كتابة، ملفات، USB، شبكة، مكالمات…) عبر واجهات أندرويد الرسمية، **بسياسة صلاحيات
   صريحة وتأكيدات وسجل تدقيق وإيقاف طارئ**.

**الوكلاء المدعومون:** OpenCode · Claude Code · Google Antigravity · OpenAI Codex.
> تصنيف README لهم (`Stable` لـOpenCode و`Beta` للبقية) **ادعاء منتج لم يُتحقَّق منه في هذه
> البيئة**، وهو مذكور كذلك في مصفوفة الميزات؛ لم يُغيَّر بلا دليل.

المشروع **مستقل** ولا يبيع أو يوفّر الخدمات الذكية نفسها: المصادقة والاشتراكات والاستدلال تتم في
الأداة الرسمية للمزوّد. الشيفرة نفسها برخصة MIT، وتشمل ذلك فقط (لكل مكوّن خارجي رخصته).

## 2) المعمارية

وحدة Gradle واحدة (`:app`) على **ستّ طبقات** + جذر تركيب (Composition Root):

| `feature` | الشاشات ومنطق العرض (محادثة، مساحات، جدولة، إعدادات، استيقاظ، مشاركة، ودجت…) | 114 | 31,266 |
| `ui` | الهيكل والتنقّل ومجموعة العرض المشتركة | 21 | 4,627 |

**المجموع: 366 ملف إنتاج و87,854 سطرًا.**

**ثلاثة مسارات تنفيذ** (وليست سلسلة خطية واحدة): المحادثة/الوكيل · أدوات الجهاز (الأهم أمنيًا) ·
الجدولة — إضافة إلى مساري الصوت ومسارات مساندة (USB، المرآة، الشبكة، OTA).

**قواعد مفروضة آليًا في CI** (لا يُقبل تجاوزها):
`scripts/check_architecture.py` (لا اعتماد صاعد بين الطبقات — الاستثناءات معدودة وموثَّقة بمرحلة

`data ⇄ runtime`** في المرحلة 2 (`data → runtime = 0`).

```

  → ملف القناة .mushrea-code/device-command.json
  → DeviceAgentBridge:
      1) الإيقاف الطارئ        2) بوابة الوجود (أداة غير معروفة = رفض)
```

حكم تحقق صريحًا بدل افتراض النجاح.

## 5) الأمان والصلاحيات

- **الأذونات المعلنة:** 30 صلاحية (29 من `android.permission.*` + `com.termux.permission.RUN_COMMAND`)،
  منها: التخزين الشامل `MANAGE_EXTERNAL_STORAGE`، الكاميرا، الميكروفون، المكالمات والسجل وجهات
  الاتصال، البلوتوث، المنبّهات الدقيقة، والإشعارات. ومزايا عتاد معلنة: كاميرا، هاتف، USB host.
- **سياسة قرار واحدة:** `ToolPermissionPolicy` هي المرجع قبل أي تنفيذ: رفض/تأكيد/سماح، مع سبب
  مفهوم يصل إلى الوكيل، ومع **رفض المعرّفات غير المعروفة** (كانت تسقط إلى AUTO قبل المرحلة 2).
- **وضع القراءة فقط** يمنع كل ما يغيّر الحالة (عدا الإيقاف الطارئ).
- **تنقيح الأسرار** قبل أي تسجيل أو تصدير (`SecretRedaction`)، وبصمة المعاملات **HMAC** لا تجزئة
  خام، ومفتاحها يموت مع العملية.
- **تخزين آمن:** بيانات الاعتماد مشفَّرة بمفتاح أندرويد (Keystore)، ومفاتيح SSH وكلمات المرور
  لا تُحفظ.
- **تثبيت الشهادات (pinning)** متاح للاتصال البعيد، ويُتحقق من صيغة البصمة (base64 SHA-256) ويمنع
  الحفظ غير الصالح، ويميّز فشل التثبيت عن فشل الثقة.
- **تضييق FileProvider** إلى مسار واحد فعلي فقط بدل مسارات غير مستخدمة (المرحلة 2).
- **لا أسرار في الشيفرة أو Git**؛ قيمة عميل GitHub تُمرَّر من إعدادات البناء.

## 6) الوكلاء والران‑تايم

| الوكيل | كيف يعمل على الجهاز | ملاحظات |
|---|---|---|
| **OpenCode** | ألباين/PRoot، ويمكن الاتصال بسيرفر OpenCode على PC | الوحيد الذي يدعم الوضعين محليًا وبعيدًا |
| **Claude Code** | ألباين/PRoot (حزمة Alpine الرسمية، تُتحقق من التوقيع) | لا يُعاد استضافته |
| **Google Antigravity** | دبيان Bookworm (لأن الثنائي يربط glibc) + ألباين | دخول OAuth، أوضاع صلاحيات ثلاثية، إعداد MCP |
| **OpenAI Codex** | ألباين/PRoot، وحدة `app-server` (JSON-RPC) | توليد صور داخل المحادثة، إدارة MCP عبر الأمر الرسمي |

**الران‑تايم:** تنزيل موثَّق (تحقق من البصمة)، تثبيت قابل للتحديث، تشغيل/إيقاف، وحالات جاهزية
تُعرض في الواجهة. تحديثات الأداة تتحكم بها التطبيق (`AGY_CLI_DISABLE_AUTO_UPDATE`).
**غير مُتحقَّق منه هنا:** التثبيت والتشغيل الفعليان يحتاجان جهازًا (PRoot لا يعمل إلّا على أندرويد).

## 8) حالة التحقق — بصراحة كاملة

**مفردات الحالة المستخدمة في المصفوفة:** `Verified` · `Partially Verified` · `Code Present` ·
`Prototype` · `Broken` · `Unsupported` · `Dead-Unused` · `Cannot Verify`.

- ✅ **مُتحقَّق منه بتشغيل حقيقي:** البناء للنكهتين، 1,408 اختبار وحدة، الفاحصون الثلاثة، detekt و
  spotless، lint، R8، وتوليد ملفات الرخص/التدقيق في CI.
- 🟡 **مُتحقَّق جزئيًا:** «التحقق بعد التنفيذ» — التغطية جزئية **بالتصميم**: ما لا تحقق مستقل له
  يُعلن `verified=false` بسبب، وهذا هو السلوك المقصود لا نقصًا.
- ⬜ **كود قائم، غير مُتحقَّق منه تشغيليًا (`Code Present`):** كل ما يحتاج جهازًا أو عتادًا — من
  فتح التطبيقات واللمس والكتابة، إلى USB والمكالمات والمرآة والشبكة والصوت.
- ⛔ **لا يمكن ادعاؤه اليوم (`Cannot Verify — Environment Limitation`):**
  - **23 اختبار جهاز لم تُنفَّذ ولا تُعدّ ناجحة بالاستنتاج**؛ تحتاج جهازًا/محاكيًا.
  - سلوك العتاد: USB host، شريحة الاتصال، الكاميرا، الميكروفون، بلوتوث، ADB لجهاز ثانٍ.
  - التحقق الشاشي لأدوات اللمس/الكتابة/التمرير/السحب **مُعلَن غير قابل للإثبات من داخل التطبيق
    نفسه** (كل نتيجة تصرّح بذلك بدل ادّعاء النجاح).
  - ادعاءات README (`Stable`/`Beta`) — لم تُغيَّر بلا دليل.

## 9) قرارات مؤجَّلة إلى المالك

| البند | الحالة والخيارات |
|---|---|
| `net.i2p.crypto:eddsa:0.3.0` | تبعية runtime يعلنها sshj وينفّذ بها `ssh-ed25519`. **0.3.0 آخر إصدار نُشر أبدًا** (لا 0.3.1) وعليه CVE-2020-36843 (تطويع توقيع **في التحقق**؛ لا يمكن تزوير توقيع لرسالة مختلفة). الخيار الجذري: ترقية sshj إلى 0.41.x (تسحب bcprov/bcpkix 1.84 وتُسقط eddsa) — تحتاج جلسة SSH حقيقية للتحقق. |
| التدقيق الموحَّد | عقده اكتمل لوكيل الجهاز (نسق 4)؛ تعميمه على الوكلاء/الجدولة/الشبكة يحتاج تعريفك لمخطط مشترك. |
| حذف سير `Branch Verification` المؤقّت | يجب حذفه قبل أي دمج. يشترط ضمان قناة بديلة: فتح PR، أو منح صلاحية `actions: write` (الوصول الحالي 403)، أو أن يعمل `Android CI` كاملًا على الفرع (حاليًا مهامّه الثقيلة مُتخطّاة على الفروع). |
| `actions/setup-java@v4` | أُعلن مهجورًا في تحذير CI؛ يُستبدل بـv5 عند حذف السير المؤقّت. |
| ادعاءات README | `Stable`/`Beta` للوكلاء — تحتاج دليل تشغيل حقيقي قبل أي تعديل. |

**ما لا يزال غير مبني (بالقياس إلى النموذج المرجعي للبرنامج):** مركز الصلاحيات **الموحَّد** عبر كل
الأنظمة (اليوم السياسة كاملة لوكيل الجهاز)، والتحقق الشاشي المستقل، والأتمتة على أجهزة اختبار.
