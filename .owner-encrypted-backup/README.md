# Encrypted owner backup

`mushrea-code-v1.2.26-signing-backup.7z` is AES-256 encrypted (7z, headers encrypted).
The archive password is **not** in this repository. It was given to the owner in the
Arena session that created the archive.

This ciphertext exists so GitHub Actions can attach it to the never-published
`owner-signing-backup` draft. Do not add it to a public release.
